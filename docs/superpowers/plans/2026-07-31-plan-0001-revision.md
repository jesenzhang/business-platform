# PLAN-0001 Foundation Hardening Revision Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reconcile PLAN-0001 with the current backend architecture baseline and produce verifiable Rust, database, storage, API, outbox, CI, and documentation evidence.

**Architecture:** Keep `document` as a framework-free core exposing domain/application ports. Move PostgreSQL adapters and HTTP delivery to `apps/business-api`; make document creation one application-level unit of work that atomically writes document, audit, outbox, and idempotency state. Keep outbox fencing and object-storage adapters in their capability crates, with real integration jobs enabled by CI services.

**Tech Stack:** Rust 1.94.1, Tokio, Axum 0.8, SQLx/PostgreSQL, AWS SDK S3/MinIO, GitHub Actions, PowerShell architecture checks.
